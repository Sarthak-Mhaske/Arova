# Attic — the previous product, frozen

Everything here belonged to **Arova v0.1**, a desktop "cognitive operating
system": a Python daemon (`arovad`) plus a Tauri UI, with voice wake-word,
a GTK desktop surface, an attention orb, an automation dispatcher, and a
twelve-layer cognition stack.

It is kept, not deleted, because a lot of it is genuinely good engineering
(see `docs/`): the cross-platform application catalog and launcher, the
restore planner with per-item provenance, the privacy-filtered browser
history reader, and the shell hook.

What it is *not* is a product. `attic/tests-legacy/` is the previous test
suite, preserved for reference and excluded from the default test run.
